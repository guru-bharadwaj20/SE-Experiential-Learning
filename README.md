# Incident Escalation & On-Call Rotation Engine

Lab work for the Software Engineering course, Dept. of CSE, PES University.

**Problem Statement #48:** A DevOps on-call
management system that organises team shift rotations, routes inbound monitoring alerts through
multi-tiered escalation ladders, and tracks incident post-mortems. Every lab in this repository
builds on this same system.

## Labs

| Lab | Topic | Deliverables |
|---|---|---|
| [Lab 1](Lab-1/) | Requirements Engineering & UML Use-Case Modelling | Requirements table, use-case diagram, use-case flow specification |
| [Lab 2](Lab-2/) | Agile Backlog Creation & Sprint Simulation in Jira | Epics and user stories, two completed sprints, burndown charts, reflection |

Further labs will be added here as the course progresses.

## Layout

Each lab lives in its own top-level folder with a short README describing its deliverables.
Diagrams are committed both as an exported PDF and as the editable draw.io source. Tool
screenshots that form part of a deliverable are committed alongside the write-up.

Course-supplied handouts and problem statements are not tracked.
